# DevOps 80 ngày — code theo video

Code của từng video trong series «DevOps 80 ngày» trên kênh Hiếu học mỗi ngày. Mỗi ngày một thư mục: README ghi bạn học gì, từng đoạn code trên video kèm lệnh chạy và kết quả máy đã chạy thật, câu đố, đáp án câu đố hôm trước và bài tập.

Cập nhật code mới: `git pull`.

## Cài đặt

Một terminal: macOS / Linux có sẵn; Windows cài WSL (`wsl --install` trong PowerShell) rồi mở Ubuntu. Lệnh trong README gõ trong terminal; đoạn đánh dấu «cố ý sai» chỉ để đọc, đừng chạy y nguyên.
